# Marriage Bureau System

A simple Marriage Bureau System developed as a Web Development Internship project.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Client Registration
- Client Directory
- Profile Search
- Matching Suggestions
- Responsive Design

## Project Description

This project provides a simple platform for registering
clients, viewing profiles, searching profiles and finding
suitable matches.
